# ✈️SkyRoute Travel Website✈️

## Overview

SkyRoute Travel is a responsive travel website built using HTML5 and CSS3.  
The website provides information about travel services and destinations, along with a booking page and a contact form.

---

## Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- Travel services cards
- Popular destinations section
- About section
- Contact form
- Travel booking form
- Social media links
- Responsive design for desktop, tablet, and mobile
- Hover effects and CSS transitions
- CSS keyframe animations

---

## Pages

### Home Page
`index.html`

Includes:
- Header and navigation
- Hero section
- Services
- Popular destinations
- About section
- Contact form
- Footer

### Book Now Page
`book-now.html`

Includes a booking form where users can enter:
- Full name
- Email address
- Departure city
- Destination city
- Departure and return dates
- Number of travelers
- Travel class
- Additional requests

## Responsive Design

The website is designed to work across different screen sizes:

- Desktop
- Tablet
- Mobile

Flexbox, CSS Grid, relative units, `minmax()`, and media queries are used to create responsive layouts.

---

## Design Choices

The website uses a travel-inspired theme with blue and purple colors based on the SkyRoute Travel logo.

The design includes:

- Sky backgrounds
- Rounded cards and form fields
- Gradient buttons
- Simple travel icons
- Clean spacing and typography
- Responsive Grid and Flexbox layouts

CSS variables are used to keep the main colors consistent throughout the website.

---

## Animations and Interactions

The website includes:

- Airplane slide animation
- Hero fade animation
- Service card hover effect
- Destination image scale effect
- Button hover transitions

These effects use `transform`, `opacity`, transitions, and keyframe animations.

---

## Forms

The project contains two forms:

### Booking Form
Located on the Book Now page and used to collect travel booking information.

### Contact Form
Located on the Home page footer and includes:

- Full name
- Email address
- Message
- Privacy Policy checkbox

Both forms include labels, input names, action, and method attributes.

---

## Accessibility and HTML Structure

The project uses semantic HTML elements such as:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

Images include meaningful `alt` text, and form fields are connected to their labels.
